# 巫行云学习 · 四年级全学年学习网站

为四年级小学生打造的语、数、英三科同步学习网站。**双击 `index.html` 即可使用**,无需联网、无需安装任何软件。

## 内容范围

| 学科 | 教材依据 | 范围 |
|------|----------|------|
| 📖 语文 | 统编(部编)版四年级 | 上册 8 单元 + 下册 8 单元,含古诗文、日积月累、习作指导 |
| 🧮 数学 | 人教版四年级 | 上册 8 单元 + 下册 9 单元,含 4 个专题复习 |
| 🔤 英语 | 人教 PEP(三年级起点) | 上册 6 单元 + 下册 6 单元,含词汇、句型、语音、语法 |

## 功能

- **单元闯关地图**:每单元都有学习目标、知识要点、重点字词、课文解析、易错提醒、例题讲解
- **🌟 课外小拓展**:每个单元附带教材之外的趣味补充知识(钱塘江观潮历史、仿生学、数学家故事、中西文化对比等,共 45 单元),全部经过核对
- **互动小测验**:每单元 8 道题左右(选择/判断/填空),练习模式逐题对答案,考试模式自动判分,全对有彩蛋
- **错题重练**:考试答错的题可以一键重做
- **学习进度 + 星星奖励**:完成单元得 1⭐,测验答对 60% 得 2⭐,满分得 3⭐,进度保存在本机浏览器
- **专题复习**:语文 6 个(含成语故事会)、数学 4 个、英语 4 个,把一学年知识串成体系
- **📚 课外阅读推荐**:每科附推荐书单,配合单元学习
- **口算大挑战**:数学专属小游戏,60 秒限时闯关
- **可打印练习卷**:每个单元测验可以一键打印(带答案版 / 无答案版)
- **每日一句 + 猫头鹰老师**:首页轮换古诗名言和学习小贴士
- **儿童友好设计**:大字、圆角卡片、闯关路径图、星星动画、答错抖动、全对撒花

## 使用说明

1. 双击 `index.html` 打开首页
2. 选择学科 → 选择学期 → 点进单元开始学习
3. 学完点击单元底部的"进入小测验",先"练习模式"熟悉题型,再"考试模式"检验成果
4. 想打印练习卷,在测验页面点"打印试卷"
5. 学习记录存在浏览器本地(localStorage),换电脑或清除浏览器数据会丢失

## 准确性说明(重要)

- 本网站内容依据现行统编语文、人教版数学、人教 PEP 英语教材编写,单元设置、古诗词、日积月累等已逐一核对
- 现代诗文受版权保护,**网站只提供作者、主题与赏析要点,不转载全文**,请对照课本原文学习
- 部分地区已开始使用修订版新教材,知识点一致,个别课文或单元顺序如有差异,**以孩子手中的课本为准**
- 家长使用前建议快速浏览一遍对应单元,与课本核对

## 文件说明

```
index.html          首页
learn.html          学习页(单页应用,支持 # 路由)
css/style.css       全部样式
js/app.js           学习引擎(路由、进度、测验、游戏)
js/data-chinese.js  语文数据(16 单元 + 5 专题)
js/data-math.js     数学数据(17 单元 + 4 专题)
js/data-english.js  英语数据(12 单元 + 4 专题)
js/data-extras.js   课外拓展(45 单元拓展知识 + 90 道增补题 + 书单 + 成语故事专题)
启动学习网站.command  双击启动局域网访问(手机/平板同 Wi-Fi 可用)
```

纯静态网页,不依赖网络,数据文件之间无模块依赖,任何现代浏览器均可打开。
